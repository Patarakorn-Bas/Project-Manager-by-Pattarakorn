## ติดตั้ง / อัปเดตบน GitHub Pages

**ติดตั้งครั้งแรก**
1. github.com → **New repository** → ชื่อ เช่น `khumngan` → **Public** → Create
2. **Add file → Upload files** → ลากไฟล์และโฟลเดอร์ทั้งหมด**ในโฟลเดอร์ `khumngan-pwa`** (ให้ `index.html` อยู่ชั้นบนสุด) → **Commit changes**
3. **Settings → Pages** → Branch: **main** / **(root)** → Save → รอ 1–2 นาที
4. เปิด `https://patarakorn-bas.github.io/khumngan/` → กดปุ่ม **ติดตั้งแอป** มุมขวาบน (iPhone: Safari → แชร์ → เพิ่มไปยังหน้าจอโฮม)

**อัปเดตจากเวอร์ชัน 1.0 (ข้อมูลเดิมไม่หาย)**
1. **สำรองข้อมูลก่อน** (เมนู → สำรองข้อมูลทั้งหมด) – เผื่อไว้
2. ใน repository เดิม: **Add file → Upload files** → ลากไฟล์ทั้งหมดของเวอร์ชันใหม่ทับ (มีโฟลเดอร์ใหม่ `templates` และไฟล์ `vendor/jszip.min.js`) → Commit
3. เปิดแอป → จะมีข้อความ **"มีเวอร์ชันใหม่ → อัปเดต"** → กดอัปเดต

## ส่งออกรายงาน Excel (รูปแบบ v4)

ปุ่ม **ส่งออกรายงาน Excel** (หน้าภาพรวม หรือเมนู) → ได้ไฟล์ควบคุมงานฉบับเต็มแบบเดียวกับไฟล์ Excel v4 ที่ใช้อยู่
- โครงการงานเดียว → รูปแบบ Plan_vs_Actual (13 ชีต) • โครงการหลายงานส่วน → รูปแบบ MultiPackage (14 ชีต)
- มีครบ: Dashboard, รายงาน, สรุปงานส่วน, แผนงาน + Gantt, S-Curve (ค่าจริงรายงวดจากประวัติผลงาน), งวดงาน, เงินงวด, VO, ขยายเวลา, ขออนุมัติวัสดุ, บันทึกสัปดาห์, รายงานกรรมการ
- **ตัวเลขคำนวณใหม่เมื่อเปิดใน Excel** (ถ้าเปิดด้วยโปรแกรมดูไฟล์บนมือถือที่ไม่คำนวณสูตร บางช่องอาจว่าง – ให้เปิดด้วย Excel หรือ Google Sheets)
- ความจุ: งานเดียว 60 รายการ • หลายงานส่วน 150 รายการ / 10 งานส่วน / 10 หมวด • งวดงาน 20 • VO/ขยายเวลา 50 • วัสดุ 100
- **ข้อมูลดิบ Excel** (ตั้งค่าโครงการ) = ตารางข้อมูลสำหรับวิเคราะห์ต่อ • ทั้งสองแบบนำเข้ากลับเป็นโครงการใหม่ได้

## สัญญาและการเงิน

1. กด **เงื่อนไขสัญญา** → ใส่ % เงินล่วงหน้า, % เงินประกันผลงาน, อัตราค่าปรับ, และสูตรค่า K (ถ้าสัญญามี) **ตามสัญญาจริง** (ค่าเริ่มต้นเป็นค่าตัวอย่าง)
2. **งวดงาน** → เพิ่มงวดตามสัญญา (เนื้องาน กำหนดเสร็จ จำนวนเงิน ผลงานสะสมที่กำหนด) → ใส่วันส่งมอบ/ตรวจรับ และดัชนี It เมื่อถึงงวด → ระบบคำนวณยอดสุทธิ • พิมพ์ **ใบสรุปการคำนวณเงินค่างาน** ได้ทีละงวด
3. **งานเพิ่ม-ลด** → เฉพาะที่อนุมัติจะปรับมูลค่าสัญญา
4. **ขยายเวลา** → เมื่ออนุมัติ วันสิ้นสุดสัญญาเลื่อนอัตโนมัติทั้งแอปและรายงาน • แสดงค่าปรับต่อวัน / ที่เกิดขึ้นแล้ว / คาดการณ์

ยอดเงินยังไม่รวมภาษีมูลค่าเพิ่ม/ภาษีหัก ณ ที่จ่าย • ค่าปรับคาดการณ์เป็นสัญญาณเตือน ไม่ใช่ยอดเรียกเก็บจริง

## AI ตรวจสเปกวัสดุ (ไม่บังคับ)

1. สมัครที่ **console.anthropic.com** → เติมเครดิต → **API Keys** → สร้างคีย์ (ขึ้นต้น `sk-ant-`)
2. ในแอป: **ตั้งค่าแอป → AI ตรวจสเปกวัสดุ** → วางคีย์ → บันทึก → **ทดสอบการเชื่อมต่อ** (ไม่มีค่าใช้จ่าย)
3. เปิดรายการขออนุมัติ → แนบรูป/PDF → **ตรวจด้วย AI** (20–60 วินาที) → ตรวจทานผล → **นำผล AI ไปใส่ในช่องที่ยังไม่ตรวจ** → ตัดสินผลพิจารณาเอง

- ผลรวมใช้กฎตายตัว: มีข้อไม่ผ่าน → แนะนำไม่อนุมัติ • มีข้อไม่พบข้อมูล → ขอเอกสารเพิ่ม • ผ่านทุกข้อ → แนะนำอนุมัติ
- **API key เก็บในเครื่องนี้เท่านั้น** ไม่อยู่ในไฟล์สำรอง (ย้ายเครื่องต้องใส่ใหม่) • จำกัดจำนวนครั้งต่อวันได้ (ครั้งที่ผิดพลาดนับด้วย)
- เอกสารที่ตรวจจะถูกส่งไปประมวลผลที่ Anthropic – ตรวจระเบียบหน่วยงานก่อนแนบเอกสารลับ
- AI ใช้ไม่ได้ในหน้าทดลองบน claude.ai (บล็อกการเชื่อมต่อภายนอก) – ใช้ได้เมื่อเปิดจาก GitHub Pages
