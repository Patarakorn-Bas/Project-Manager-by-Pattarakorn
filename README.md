# คุมงานก่อสร้าง (แอปติดตั้งได้) — คู่มือ

แอปสำหรับผู้ควบคุมงานใช้งานคนเดียว: ติดตามความก้าวหน้างานก่อสร้าง (งานเดียว หรือโครงการหลายงานส่วน) • S-Curve อัตโนมัติ • รายงานประจำวัน • รายงานรายสัปดาห์ (บันทึกข้อความเสนอคณะกรรมการ) • ขออนุมัติใช้วัสดุ (ตรวจเทียบรายการประกอบแบบ กฟภ. 2568)

- **ติดตั้งลงคอมพิวเตอร์และมือถือได้** เปิดจากไอคอนเหมือนโปรแกรม
- **ใช้งานออฟไลน์ได้** ข้อมูลเก็บในเครื่อง ไม่ต้องมีบัญชี ไม่ต้องล็อกอิน
- ⚠️ ข้อมูลอยู่ในเครื่องที่ใช้งานเท่านั้น → **สำรองข้อมูลสัปดาห์ละครั้ง** (เมนู ☰ → สำรองข้อมูล)

---

## ติดตั้งบน GitHub Pages (ครั้งเดียว ~10 นาที)

ทำแบบเดียวกับแอป kw-civil-answers

1. เข้า github.com → ปุ่ม **＋ → New repository** → ตั้งชื่อ เช่น `khumngan` → เลือก **Public** → **Create repository**
2. ในหน้า repository กด **uploading an existing file** (หรือ Add file → Upload files)
3. แตกไฟล์ zip แล้ว **ลากไฟล์และโฟลเดอร์ทั้งหมดในโฟลเดอร์ `khumngan-pwa`** ลงไป (ต้องเห็น `index.html` อยู่ชั้นบนสุด ไม่ใช่อยู่ในโฟลเดอร์ย่อย) → **Commit changes**
4. ไปที่ **Settings → Pages** → Source: **Deploy from a branch** → Branch: **main** / **/(root)** → **Save**
5. รอ 1–2 นาที แล้วเปิด `https://patarakorn-bas.github.io/khumngan/`
6. **ติดตั้งเป็นแอป**
   - คอมพิวเตอร์ (Chrome/Edge): กดไอคอน ⊕ ท้ายช่องที่อยู่เว็บ หรือปุ่ม **⬇ ติดตั้ง** มุมขวาบน
   - Android (Chrome): เมนู ⋮ → **ติดตั้งแอป**
   - iPhone/iPad (Safari): ปุ่มแชร์ ⬆ → **เพิ่มไปยังหน้าจอโฮม**

> ข้อมูลผูกกับ **ที่อยู่เว็บ + เบราว์เซอร์ + เครื่อง** ถ้าเปลี่ยนชื่อ repository ที่อยู่เว็บจะเปลี่ยนและจะไม่เห็นข้อมูลเดิม ให้สำรองก่อนแล้วกู้คืนในที่อยู่ใหม่

## เริ่มใช้งาน

- **ลองดูก่อน:** หน้าหลัก → "ลองโครงการตัวอย่าง" (โครงการ 6 งานส่วน มีรายงานประจำวัน รูป และวัสดุตัวอย่าง) ลบทิ้งได้ภายหลังที่ ตั้งค่าโครงการ → ลบโครงการ
- **โครงการใหม่:** กด "＋ โครงการใหม่" → เลือก **งานก่อสร้างงานเดียว** หรือ **โครงการหลายงานส่วน** → กรอกข้อมูลสัญญา → เพิ่มรายการงาน (ทีละรายการ หรือ "วางจาก Excel")
- **จากไฟล์ Excel v4 ที่มีอยู่:** หน้าหลัก → "📗 นำเข้าจาก Excel v4" → เลือกไฟล์ → ระบบสร้างโครงการพร้อมรายการงานและผลงานให้ (ตรวจแล้วตัวเลขตรงกับ Excel)

## การใช้งานประจำวัน

| เมนู | ใช้ทำอะไร |
|---|---|
| 📊 ภาพรวม | ผลงานแผน/จริง SPI S-Curve ความก้าวหน้ารายงานส่วน/หมวด รายการที่ต้องติดตาม • เตือนถ้ายังไม่บันทึกรายงานวันนี้ |
| 🧱 ผลงาน | รายการงาน (แยกตามงานส่วน กรอง/ค้นหาได้) • กด **อัปเดต** เพื่อบันทึก % พร้อมวันที่ – ระบบเก็บเป็นประวัติ ดู/ลบประวัติได้ |
| 📝 รายวัน | สภาพอากาศ • คนงาน (ปุ่มลัดประเภทช่าง + คัดลอกจากวันก่อน) • เครื่องจักร • **แก้ % ผลงานของรายการที่ทำวันนี้ได้ในหน้าเดียว** • งานที่ทำ วัสดุ การทดสอบ ปัญหา คำสั่ง • รูปถ่าย • **บันทึกอัตโนมัติขณะพิมพ์** • พิมพ์ "บันทึกการปฏิบัติงานประจำวันของผู้ควบคุมงาน" |
| 🗓️ รายสัปดาห์ | **รวบรวมจากรายงานประจำวันให้อัตโนมัติ**: วันทำงาน/วันฝนตก คนงานเฉลี่ย เครื่องจักร ผลงานต้น-สิ้นสัปดาห์ รายการที่คืบหน้า • ดึงข้อความงานที่ทำ/ปัญหา/วัสดุ มาให้แก้ไข • เลือกรูปแนบ • พิมพ์ **บันทึกข้อความ เรียน ประธานกรรมการตรวจรับพัสดุ** พร้อม S-Curve ช่องลงนาม และภาคผนวกรูป |
| 📦 วัสดุ | ยื่นขออนุมัติ → เลือกหมวดตามรายการประกอบแบบ กฟภ. 2568 (516 ข้อ 49 หมวด) หรือพิมพ์ข้อกำหนดเอง → แนบรูป/PDF → **ตรวจทีละข้อ** (ผ่าน/ไม่ผ่าน/ไม่พบข้อมูล/ไม่เกี่ยวข้อง) → ระบบแนะนำผลพิจารณา → พิมพ์รายงานขออนุมัติพร้อมช่องลงนาม 3 ฝ่าย • เตือนเมื่อจะอนุมัติไม่ทันวันเริ่มงาน |

**พิมพ์/ทำ PDF:** กด 🖨️ แล้วเลือกเครื่องพิมพ์ "บันทึกเป็น PDF" (Save as PDF)

**S-Curve อัตโนมัติ:** ทุกครั้งที่อัปเดต % (จากแท็บผลงานหรือรายงานประจำวัน) ระบบจำวันที่ไว้ เส้นผลงานจริงจึงสร้างเองย้อนหลังได้ ไม่ต้องกรอกค่าสะสม

## สำรอง / ย้ายเครื่อง

- เมนู ☰ → **สำรองข้อมูลทั้งหมด** → ได้ไฟล์ `สำรอง_คุมงาน_วันที่.json` (รวมรูป) → เก็บใน Google Drive / OneDrive
- ย้ายเครื่อง: เปิดแอปในเครื่องใหม่ → ตั้งค่าแอป → **กู้คืนจากไฟล์** (เลือก "รวมกับข้อมูลเดิม" หรือ "แทนที่ทั้งหมด")
- แอปเตือนที่หน้าหลักเมื่อไม่ได้สำรองเกิน 7 วัน
- **ส่งออก Excel** (รายโครงการ) ใช้ดู/ส่งต่อ และนำเข้ากลับเป็นโครงการใหม่ได้

## อัปเดตแอปเวอร์ชันใหม่

อัปโหลดไฟล์ใหม่ทับใน repository เดิม (Add file → Upload files → Commit) • เปิดแอป จะมีข้อความ "มีเวอร์ชันใหม่ → อัปเดต" • **ข้อมูลเดิมไม่หาย** (อยู่ในเครื่อง ไม่ได้อยู่ในไฟล์แอป)

เมื่อขอให้ Claude เพิ่มความสามารถ ให้แนบไฟล์ `app.js` (หรือ zip ทั้งโฟลเดอร์) เวอร์ชันล่าสุดมาด้วย

## ข้อจำกัดของต้นแบบนี้

- ใช้งานคนเดียว ข้อมูลไม่ซิงก์ข้ามเครื่องอัตโนมัติ (ใช้สำรอง/กู้คืนแทน)
- ยังไม่มี: งวดงาน/เงินงวด/ค่า K, งานเพิ่ม-ลด, ขยายเวลา/ค่าปรับ, AI ตรวจสเปก (มีในระบบเดิม – เพิ่มเข้ามาได้เมื่อต้องการ)
- ถ้าใช้หลายเบราว์เซอร์ในเครื่องเดียว ข้อมูลแยกกันคนละชุด – ควรใช้เบราว์เซอร์เดียว (หรือแอปที่ติดตั้ง)
